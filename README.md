This repository documents my engineering roadmap, practical research, and hands-on artifacts as I transition into **AI Trust, Safety, and Red Teaming**. 

## Track Structure
- **owasp-genai/**: Threat mappings, custom attack examples, and agentic/MCP vulnerability studies.
- **mitre-atlas/**: Real-world case study kill-chain breakdowns.
- **portswigger/**: Web and API security notes (BSCP track).
- **pyrit / garak / promptfoo/**: Custom AI red-teaming harnesses and evaluation scripts.
- **final-report/**: Comprehensive end-of-roadmap vulnerability assessment project.
